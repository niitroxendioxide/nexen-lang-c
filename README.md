# How to build

If on **NixOS**, simply run: 
`nix-shell` to enter the nix-shell mode, and then build the project normally:
```sh
chmod +x run.sh
./run.sh
```

If **not** on NixOS:
You must have gcc/clang and cmake installed, then run the build commands normally:
```sh
chmod +x run.sh
./run.sh
```

# How to run
Once the executable was built, run:
`./build/nexen input/main.nx`

You can add the optional flag `--tokenize` to see all tokens generated by the program, and you an replace input/main.nx with any file,
as there's currently no validation on the source or extension (you can compile a .txt)
