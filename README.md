# How to build

If on **NixOS**, simply run: 
`nix-shell` to enter the nix-shell mode, and then build the project normally:
```sh
chmod +x run.sh
./run.sh
```

If **not** on NixOS:
You must have gcc/clang and cmake installed, then run the build commands normally:
```sh
chmod +x run.sh
./run.sh
```

If on **Windows**, you must also run this line to ensure the usage of gcc, or run it at your own discretion, but GCC was used to build this project.
```powershell
cmake -G "MinGW Makefiles" -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ -B build
```

# How to run
Once the executable was built, run:
`./build/nexen input/main.nx`

You can add the optional flag `--tokenize` to see all tokens generated by the program, and you an replace input/main.nx with any file,
as there's currently no validation on the source or extension (you can compile a .txt)



# Example code
```rs
/*
    Since github has no syntax highlighting for the language rn, rust is used as example.
    This is an example assumming you have a module 'data' with:

    export let exchange_rate = 0; //[any number here]
*/
import data = "data"

let rate = data::exchange_rate;
fn calculate_usd_to_rate(usd_count) {
    return rate * usd_count;
}

let prices = [82, 16, 37.5];
for val in prices {
    let converted = calculate_usd_to_rate(val);
    print(val, "$US =", converted, "$EX");
}
```
